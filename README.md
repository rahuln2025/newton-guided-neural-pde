# Learning Solver-Guided Warm Starts for PDE Solves

Code for the NeurIPS 2026 workshop paper: **When Newton Helps Newton: Learning Solver-Guided Warm Starts for PDE Solves**.

**PDE:** 2D nonlinear Poisson–Helmholtz–Boltzmann on the unit square  
`-Δu + k²uⁿ = f(x,y)`,  `u = 0` on ∂Ω

---

## Environment

```bash
# Python 3.10, PyTorch 2.7.1+cu118, NGSolve
pip install -r requirements.txt
```

NGSolve must be installed separately: https://ngsolve.org/downloads

---

## Repository Structure

```
solver.py                   # NGSolve FEM solver + data generation
model_pdes.py               # UNet2D architecture
train.py                    # Solver-guided training (main method)
train_datadriven.py         # Data-driven baseline
inference.py                # Evaluation
utils_data_pdes.py          # Dataset generation utilities
utils_train_with_solver.py  # Training loop (solver-guided)
utils_train_datadriven.py   # Training loop (data-driven)
utils_plots.py              # Plotting utilities
configs/                    # YAML configs for all paper experiments
```

---

## Step 1 — Generate Data

Data is generated by running the FEM solver (NGSolve) over a sampled parameter space.  
Each config specifies `n_pts`, sample counts, and parameter ranges.

```bash
# Solver-guided dataset (256 train / 32 val / 32 test, grid 64×64)
python utils_data_pdes.py --config configs/config_256_solver_M1.yaml

# Data-driven dataset (same parameter space, stores full solutions)
python utils_data_pdes.py --config configs/config_256_dd.yaml
```

Output `.h5` files are written to the path specified in `data_config.train_path` / `val_path` in the config.

Repeat with `config_128_*.yaml` and `config_512_*.yaml` for other resolutions.

---

## Step 2 — Train

Four experiment types from the paper:

### (a) Solver-guided — M Newton steps as training signal

```bash
# M=1
python train.py --config configs/config_256_solver_M1.yaml

# M=3
python train.py --config configs/config_256_solver_M3.yaml

# M=5
python train.py --config configs/config_256_solver_M5.yaml
```

### (b) Data-driven baseline

```bash
python train_datadriven.py --config configs/config_256_dd.yaml
```

Checkpoints and TensorBoard logs are saved under `runs/<run_name>/<run_id>/`.

To monitor training:
```bash
tensorboard --logdir runs/
```

---

## Step 3 — Inference

```bash
python inference.py --config configs/config_256_solver_M1.yaml \
                    --ckpt runs/256_UNet2D_solver_M1_fixed/<run_id>/checkpoints/best_model.pt
```
